## Mobile opening-panel spacing correction

Wyatt clarified that the large blank band between opening copy and its actions is a mobile-only defect across the site, including the Answers library and individual Answer pages. Desktop layout is locked and must remain unchanged.

The cause was the max-width 700px rule forcing every `.fc-page-intro` to fill the remainder of `100dvh` after the fixed 300px mobile hero. Because the action row uses `margin-top:auto`, tall phones pushed the buttons far below the copy and created the visible empty area. The mobile rule now uses content height (`min-height:0`) while retaining the same hero, type, gaps, buttons and 24px panel bottom padding. The change is confined to max-width 700px. The 701px-plus tablet and desktop rules are unchanged.
