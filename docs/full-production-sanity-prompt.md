# Full production sanity review: execution prompt

Execute a bounded, evidence-based review of all focusChrist public pages and meaningful interactions. The owner's goal is a beautiful, coherent and deeply useful place to learn of Jesus Christ from a faithful Latter-day Saint perspective. Do not confuse an independent resource with an official or exhaustive representation of the Church. Do not claim to have researched every LDS website.

Read current Master/Focus controls, the connected-study standard, repository instructions and current production state. Inventory all main sections, answer studies, artwork studies, images/viewers, Ask entry points, history interactions and utility recovery paths. Verify deployment and actual live content before relying on earlier success.

Review doctrinal and scriptural claims against scripture and official Church teachings. Give appropriate supporting roles to the Joseph Smith Papers, Church History, Gospel Library, General Conference and BYU primary scholarship where relevant. Distinguish authoritative teaching, historical evidence, scholarship, interpretation and original reflection. Check important context and verse ranges. Do not add sources just to inflate link counts. Preserve compassion, agency, respectful disagreement and approved art. Correct substantive gaps instead of padding sound content.

Review readability and visual hierarchy on representative live pages; test navigation, study-to-study continuity, image loading, details and full-size viewing, return paths and live Ask contracts. Exercise desktop and mobile only through supported browser capabilities and record exactly what was rendered. Check responsive rules, titles/descriptions, canonical URLs, structured data, social previews, robots, sitemap coverage and accurate modification dates, HTTP status and local references. Run required repository gates and an independent review before changes are committed.

The owner clarified that “advertised all over the internet” means URLs are correctly exposed through search, sitemaps, internal links, social previews and existing relevant channels, not a new advertising campaign. Check public discoverability with real search results and authenticated search-console evidence when available. Verify existing relevant social/channel backlinks. Separate crawlability, indexing, public promotion and actual visitor acquisition. A search result is not proof of traffic; a submitted sitemap is not proof of indexing. Repair authorized site-owned discovery defects. No paid advertising, mass posting, invented endorsements or unsolicited messages. Prepare any recommended new public promotion as concrete destination-specific copy before seeking any required approval. Do not promise presence everywhere on the internet.

Write an evidence record with pass/fail/unverified status. Repair concrete blockers, release through the authorized path and verify deployed results. Then execute the separate challenge prompt below before giving a completion verdict.

Bound the process: one comprehensive review, one correction batch, one independent challenge and at most one focused follow-up correction/retest for new blockers. Do not loop toward an undefined perfect score. If an external limitation remains, name it honestly rather than declaring all requirements done.
