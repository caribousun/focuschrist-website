# Independent resource review

Local review of 12 official Church destinations and 11 downloaded thumbnails. This is source/thumbnail verification, not deployment or owner artwork approval. Reviewer inspected the actual downloaded images. No generated illustration has been substituted for an official resource thumbnail.

## Retrieval and provenance

All 12 source pages retrieved successfully. All 11 supplied thumbnails retrieved successfully at 640 pixels wide using the same Church image identifiers and the Church image service size parameter. No enlargement fallback was needed. `resource-candidates.json` records the original page thumbnail URL, actual download URL, local preview path, dimensions, SHA-256, source heading, source description, image alt text and conference bylines. The originals are in sibling `../atonement-preview/resources`, outside the website repository.

The forgiveness resource supplies no thumbnail in the retrieved page. Use a text resource card. Do not borrow an unrelated picture or imply a generated image came from this page.

## Integration recommendations

- Use the exact official destination and image identifiers in the JSON when adding site provenance records. Record the resized download URL as the fetched image URL; retain the source page URL separately.
- Preserve natural aspect ratios. The 1985 frame has archival softness; a larger response does not guarantee newly available detail.
- Use speakers' names in thumbnail descriptions only where the official source byline and actual frame agree, as verified above.
- Keep these resource images visibly attached to their official resource cards. Their different artistic representations of Christ should not be substituted into new scene artwork or the approved site hero.
- Distribute cards by their study purpose rather than placing all 12 in one repetitive block. The existing sources cover sacrifice, repentance, grace, burdens, Resurrection and covenants. The new Pearl of Great Price and Book of Mormon chapters can use their primary scripture passages directly rather than unrelated conference thumbnails.
- This review checks source/subject correspondence and retrieval. It does not establish unrestricted image licensing or substitute for the site's existing source-ledger and release gates.
