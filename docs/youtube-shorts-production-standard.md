# focusChrist and @theRisen636 Shorts Production Standard

Updated: 2026-09-03

## Purpose

Create reverent, visually strong Shorts that deliver one truthful spiritual message and lead interested viewers to the exact focusChrist study path.

## Story structure

- One Short, one primary idea.
- Open with an accurate hook, not manufactured suspense.
- Establish the question, tension, or promise immediately.
- Develop the message with only the context needed to understand it.
- End with the spiritual conclusion or invitation promised by the hook.
- Use Ask as a secondary continuation path, not as a generic destination for every video.

## Visual structure

- Compose vertically at 9:16.
- Keep faces, important action, and captions within mobile-safe areas.
- Use cinematic photographic realism and the approved focusChrist likeness of Jesus Christ.
- Reject cartoon, painted, glossy, game-rendered, fantasy, or exaggerated imagery.
- Change framing or visual emphasis often enough to support retention, but do not create frantic motion.
- Keep captions readable against every shot.

## Accuracy and routing

- Use the exact scripture, teaching, testimony, or historical source that supports the message.
- Use truthful titles and descriptions.
- Link to the most relevant permanent focusChrist page.
- Preserve the source, destination page, narration, caption copy, and visual assets with the production record.

## Learning loop

Review each release using:

- First seconds retention and swipe-away rate.
- Average view duration and completion rate.
- Replays.
- Returning viewers.
- Subscriber conversion.
- Search terms and traffic source.
- Link clicks and continuation into focusChrist.

Make production changes only after comparing a repeatable pattern across multiple Shorts. Record what changed and why.
